# Image Style Prompts for OpenCode

Here are a few prompts you can use with OpenCode, depending on your preferred style and workflow:

### Option 1: Direct & Concise (Best for quick updates)

> Maintain the existing photo-realistic style of the images throughout the UI. Please add more realistic image samples/cards to expand the collection, using high-resolution, life-like photography placeholders that match the theme.

---

### Option 2: Detailed & Technical (Best for precise UI/UX specs)

> Please update the UI with the following image guidelines:
> 1. **Style Consistency:** Ensure all existing and new images maintain a clean, realistic, photo quality (avoid cartoonish, heavily stylized, or low-res placeholders).
> 2. **Add More Images:** Increase the number of displayed image cards/items across the layout.
> 3. **Placeholders:** Use realistic stock photo placeholders (e.g., via Unsplash or similar high-quality image URLs) that seamlessly fit the current theme and color scheme.

---

### Option 3: Conversational (Best for quick iterations)

> Can you add more image cards/elements to this layout while making sure all new and existing images look completely realistic and consistent in lighting and tone?
